# Daya Cipta Mandiri - Corporate Website

Website resmi perusahaan yang mengintegrasikan 3 pilar layanan utama:
1. **Pelatihan Lembaga Keuangan**: SDM, Operasional, Manajemen Risiko, Kepatuhan (POJK/BI), Loan Scoring, dan Key Performance Indicators (KPI).
2. **Penyedia Jasa Tenaga Kerja (Outsourcing)**: Jasa Keamanan (Security berlisensi Mabes POLRI / Gada Pratama), Jasa Kebersihan (Cleaning Service higienitas korporat), dan Driver operasional eksekutif.
3. **Jasa & Konsultasi Hukum**: Legal opinion bisnis, somasi & mediasi non-litigasi, restrukturisasi hutang, serta pendampingan litigasi pengadilan niaga & perdata.

---

## Fitur Utama

- **Tampilan Korporat Modern**: Bebas dari template generic (*Anti-AI Slop*), palet warna *Deep Navy, Slate, Compliance Teal, & Executive Gold*.
- **Tanya Jawab (FAQ Dinamis)**: Accordion interaktif per kategori layanan.
- **Live Chat / WhatsApp Bubble**: Widget floating di pojok kanan bawah dengan opsi konsultasi cepat.
- **Fitur Kontak Telepon (Click-to-Call)**: Panggilan langsung nomor kantor untuk perangkat mobile & desktop.
- **Formulir Kritik & Saran**: Validasi formulir online dengan notifikasi sukses dan tembusan email admin.
- **Informasi Rekening Resmi Bank**: Informasi rekening resmi BCA (2521362873) dilengkapi tombol *1-Click Copy No. Rekening* dan peringatan keamanan transaksi (*Anti-Fraud Notice*).

---

## Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS + PostCSS + Autoprefixer
- **Icons**: Lucide React
- **Typography**: Google Fonts (Plus Jakarta Sans & Montserrat)

---

## Menjalankan Proyek Secara Lokal

```bash
# 1. Install dependencies
npm install

# 2. Jalankan server development
npm run dev

# 3. Build untuk produksi
npm run build

# 4. Preview hasil build
npm run preview
```
